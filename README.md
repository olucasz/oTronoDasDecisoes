# O Trono das Decisões

Base inicial da landing page de pré-venda do livro **O Trono das Decisões**, de Mateus Chaves Generoso.

## Como executar

Opção direta:

```bash
open index.html
```

Opção com servidor local:

```bash
npm run dev
```

Depois acesse:

```txt
http://localhost:5173
```

## Estrutura

- `index.html` — Header e Hero inicial.
- `docs/PROJECT_CONTEXT.md` — contexto visual, decisões e direção técnica.
- `docs/ASSET_MANIFEST.md` — inventário dos assets principais.
- `public/assets/` — assets organizados para uso na landing.
- `src/styles/` — CSS dividido por tokens, base, layout, componentes e seções.
- `src/js/` — JavaScript simples para menu mobile e animações discretas.

## Escopo desta etapa

Esta versão implementa apenas a estrutura base, o Header e a Hero responsiva. As próximas seções, checkout e copy final ainda não fazem parte desta etapa.
